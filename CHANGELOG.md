# Changelog

## 0.1.0

First release.

- Sounds a mob was still making stop when it dies: the enderman's stare, the creeper's fuse hiss, the pillager's crossbow loading.
- The mob's own death sound still plays (`keep_death_sound=true` in `config/hushmortem.properties`).
- Client-side only, no Fabric API needed.
- One jar for Minecraft 26.1.2, 26.2 and 26.3.
